Version 0.4.20 of the LEGO Battles PC port: the settings menu in LEGO Battles' own style, and fewer duplicate lobby posts on Discord.

The settings menu opens with F1 or Esc. Settings > General > **Install update** updates the game in place.

## New

- **LEGO Battles menu style** (Settings > Display > Menu style, now the default): the menus use the game's own font, its brick buttons and its colours, all taken from your cartridge when the game starts. The menu entry you are on is a light brick, the others dark; Quit and Reset are red bricks. Pixel art stays sharp at whole sizes, so in this style the UI scale rounds to 1x, 2x or 3x. Choose "Port" for the previous look.

## Fixes

- **Lobbies were posted twice on Discord** when the host used "Both" master servers: each server announced the same lobby. The second server now lists the lobby without posting it. A host who chose the second server alone is posted as before, and if the main server gives no listing, a host on "Both" is listed and posted on the second server.
  - The second server must also be updated for this to take effect there.

## Still open

- **Specials invisible when zoomed out** (Enhanced) and **phantom ties at the very start of an online match**: not reproduced yet; we asked the reporters for details.
- **EMP on a hotwired vehicle** froze an online match in older versions. Not reproduced; please send the session log if it happens.
- **Custom units drawn with another unit's sprites**: held back after it corrupted memory in a test.
- **Computer players in online matches**: planned for a later version.

## Please update together

- Online, everyone in a lobby should use the same version.
