The fourth test build of the LEGO Battles PC port. **This is an early pre-release: every feature new in it is not yet tested in real play.** Each one has only been checked in automated runs on one PC (online features between two copies on that PC), not by players and not across the internet. Expect rough edges, and please report what you find on the [issue tracker](https://github.com/AgitationSkeleton/legobattles-pc/issues/new/choose).

## What's new (not yet tested in real play)

- **Online chat.**
  - In an online lobby or match, **T** opens a chat box and **Enter** sends; Esc closes it. T does nothing offline.
  - Received messages pop up for a few seconds, led by the sender's hero icon. This is on by default; the toggle is in the Multiplayer tab > Chat.
  - The key can be changed there too.
- **A swear filter**, on by default (the Multiplayer tab > Chat).
  - Swear words in chat and in players' names, including the names in the game's own lobby, are shown as "ziff" ("ziffing" for -ing words), in the same capitals.
  - Turning it off shows them as written, at once.
  - It can occasionally catch an innocent word that contains one.
- **Custom maps from loose folders.**
  - Extract maps from the community map archive into `mods\maps\` beside the executable, as they come. Each map's folder needs its `.map` and four minimap files.
  - They appear after the game's own maps in Free Play. Up to 30 load; the log lists any left out.
- **Custom maps online.**
  - A host can now pick a mod map. Each player's copy is matched by its content, so the two `mods` folders need not be the same.
  - A player who doesn't have the host's map is told so and can't ready, so the match can't start without them. Missing maps are not downloaded automatically yet.
- **A Gold Brick value** in Balance Presets: what a Gold Brick pickup gives (1000 in the game). Offline only, like every Balance value; recordings carry it.
- **Neutral creatures in armies** (Wolf, Robot, Shark), an option that is off by default. Online, the host's setting decides.
- **Mod Map Palettes**: an option for the palette mod maps use.
- **The ban list** can be exported and imported as a file, like the Balance values.
- **Smooth 3D Models** (Display, off by default): draws the 3D-model units without the DS's dark outline, smoothed.
- **Zoom is recorded**, so a session zoomed during play replays correctly.

## Known limitations

- **Testing so far.** Everything above has only had automated checks on one PC. Chat, the filter and mod maps online have not yet been used between two different PCs.
- **Names.** A host with the swear filter on also shows its filtered names to the players who join. Your own name is always shown to you as you wrote it.
- **Mod maps** are not fetched from the archive yet; every player needs the host's map in their own `mods\maps\`.
- **Latency.** The DS wireless protocol waits for a reply on every exchange, so across the internet the connection's round-trip time limits the frame rate.
- **Routers.** Two routers that both renumber ports for every destination (some carrier-grade NAT), with UPnP unavailable, still cannot connect.
