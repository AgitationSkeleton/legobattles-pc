Version 0.4.3 of the LEGO Battles PC port: custom units get their own heads, long army lists scroll, and three player requests.

The settings menu opens with F1 or Esc. Settings > General > **Install update** updates the game in place.

## New

- **Custom unit heads.** A custom unit's `portraits/head.png` is its head in the game's army screen and in the Team Builder. Shared and lobby units carry it.
- **Army lists scroll.** When a slot has more units than its 25 cells (for example with custom heroes), a scroll bar appears beside the list in the game's army screen. Use its arrows, drag it, or turn the mouse wheel over the list. The Team Builder's grid scrolls too. Every custom hero is now offered, not only the first.
- **Export as Entities.ebp** (Balance). Saves your balance values as an `Entities.ebp` file. With Import from ROM, this converts balance patches both ways between `.json` and `.ebp`.
- **Brick menus stay open when a unit dies** (Settings, next to the number-key option; on by default). If a selected unit dies while a spell or build list is open, the list stays open for the units that are left. It closes as before if none of them can use it.

## Fixed

- **Map names** in the lobby list, match pictures and Rich Presence could stay as a file code (such as `mp07`) for the whole match. The name is now looked up again until it is known.

## Files

- `LegoBattles-PC-0.4.3.zip`: the game.
- `LegoBattles-PC-0.4.3-runner-source.zip`: the corresponding source of the runner (GPL-3.0-or-later). The port's own source is this repository at this tag.
