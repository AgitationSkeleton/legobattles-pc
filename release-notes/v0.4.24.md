Version 0.4.24 of the LEGO Battles PC port: the lobby servers are hardened against floods and slow-connection attacks (GitHub issue #2).

The settings menu opens with F1 or Esc. Settings > General > **Install update** updates the game in place.

## Lobby servers

A security test on a self-hosted lobby server found that one machine could:
- take the server down by holding connections open;
- list hundreds of lobbies and flood the Discord lobby channel;
- list a lobby at any address it liked.

All three servers are fixed: the main server, the fallback, and `services/master-server/master_server.py` for anyone who runs their own.

- **Slow and held connections:**
  - a read times out after 10 s, and a connection ends after 20 s in all;
  - at most 96 requests are handled at once, 8 from one address, and one more is turned away at once.
- **Limits per address:** 6 lobbies listed every 10 minutes and 3 at once, plus request-rate limits. These are far above what the game sends, and the server holds 200 lobbies in all.
- **The lobby list:** at most 100 lobbies per reply, with the total.
- **Discord lines are rate-limited:**
  - for everyone together, and per address;
  - when lines are dropped, the next line that goes says how many.
- **A lobby is listed at the address the server sees.** A host's own address is used only when it matches, or when the host is on the server's own network.
- **HEAD requests** are answered properly. The server no longer names its Python version.
- **Running `master_server.py` under systemd:**
  - the example unit's `TasksMax` is now 256;
  - `--max-connections` sets how many requests it handles at once;
  - `--trusted-proxy` supports running it behind a reverse proxy.
  - See its README's Limits section.

## Fixes

- **A lobby server's own "slow down" answer no longer switches the game to the fallback server.** Only Cloudflare's own limit pages do.

## For server operators

- Update `services/master-server/master_server.py` and restart it.
- A unit that pulls the repository before starting (`ExecStartPre=git pull`) gets the update on a restart.
- Raise `TasksMax` to 256 in the unit.
