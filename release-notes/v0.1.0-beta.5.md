The fifth test build of the LEGO Battles PC port. **This is an untested pre-release: nothing new in it has been tested in real play yet.** Each change was only checked in automated runs on one PC, with online features tested between two copies on that PC. None has been tried by players or across the internet. Expect rough edges, and please report what you find on the [issue tracker](https://github.com/AgitationSkeleton/legobattles-pc/issues/new/choose).

## What's new (untested in real play)

- **Online games use the host's balance.**
  - A joining player now plays on the host's Balance settings: the balance pack, Make All Builders The Same, and every value set in the Balance menu. Your own settings come back when you leave.
  - Both sides check a fingerprint of the settings, and a player cannot ready until they match.
  - Before this, each player kept their own values, which could make a match go out of sync.
- **Fixed: neutral creatures online.** A joining player now uses the host's creature prices too.
- **Fixed: the Imperial builder in the Balance menu.** Editing it could make the game lose track of its own unit data. This happened offline too.
- **Missing mod maps are downloaded.**
  - If the host picks a mod map you don't have, the game looks it up in the community map archive and downloads it into `mods\maps\_archive`. Restart the game, then join again.
  - On by default; turn it off with Multiplayer > "Fetch a host's mod map I don't have".
- **Master server:**
  - **Both:** lists your lobby on both known servers (lbserver.viosarcade.xyz and king.legobattles.win) and shows the lobbies of both.
  - **HTTPS:** the game talks to the master server over HTTPS when the server offers it, and over plain HTTP when it doesn't.
- **The Better Free Play maps pack's maps** now use the detail tiles of the map slot they were made for.
- **The pause menu and the quit dialog** were checked at full zoom-out and draw correctly.

## Known limitations

- **Testing so far.** Everything above has only had automated checks on one PC. The online features have not been used between two different PCs, and "Both" was only tried against servers on the same PC.
- **A downloaded map** needs a restart before it can be played.
- **Still not seen in a real battle** (built, off by default): EMP on transports, hotwired transports leaving their old owner, and the fix for a freeze when a hotwired transport's occupants are destroyed.
- **Latency.** The DS wireless protocol waits for a reply on every exchange, so across the internet the connection's round-trip time limits the frame rate.
