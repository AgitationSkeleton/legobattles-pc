Version 0.4.7 of the LEGO Battles PC port: up to 128 custom units, a fix for the freeze after Reset, and transports unload from the top screen.

The settings menu opens with F1 or Esc. Settings > General > **Install update** updates the game in place.

## New

- **Up to 128 custom units** (was 9). The 9 came from the game's own unit table. The port has used its own, larger table for a while, so the limit only stood in the way. Online, a host's whole set reaches the joiners however many there are.
- **Custom units: Stats tab.**
  - **Projectile** and **spell_1..5** are lists with names instead of numbers. Each projectile also lists the stock units that fire it.
  - **In-game name** ("display_name" in unit.json): what the game shows in battle and on the unit's cards. It need not be unique, so several units can all be "Builder" like the stock builders. "Name" is still what the menus list the unit by.

## Fixed

- **The game froze after Reset with custom units on.** This covers the menu's Reset, "Load new units now" and "Load new maps now". The custom units put the previous boot's unit table back into the fresh game.
- **Transports now unload from the top screen.** Clicking an occupant icon on a selected transport unloads one unit of that kind. The first three icons were taken for a building's queue, so the click went through to the battlefield and selected a unit there.

## Good to know

- **Build speed compared with melonDS.** "Steady game pacing (30 Hz)" (Display, on by default) runs the game in even steps, about 19% slower than melonDS, which is probably nearer a real DS. Turn it off to play at melonDS's pace.
