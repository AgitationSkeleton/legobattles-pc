Version 0.3.7 of the LEGO Battles PC port: Action Replay codes, your own level palettes, pause and frame advance, and the lobby's server name.

The settings menu opens with F1 or Esc. Settings > General > **Install update** updates the game in place.

## New

- **Action Replay codes** (Cheats > Action Replay). Enter Action Replay DS codes, give each a name and tick the ones you want; they run every frame. Import and Export use `ar_codes.txt` beside the game, and you can save and load named sets of codes. Offline only for now: online they are held off, because the game cannot yet check that every player has the same codes. While any code is on, the match's score is not reported. Session recordings don't include codes.
- **Your own level palettes** (Settings > Display). Put `.nclr` palette files (the format of the game's own tileset palettes) in the `mods/palettes` folder and pick one for King, Pirate and Mars levels. The game's own colour animation is kept. Only you see it.
- **Pause and frame advance** (Settings > Controls > TAS controls, off by default). F5 pauses and resumes the game, F6 advances one frame while paused, and holding Tab still fast-forwards. Offline only.
- **Which server a lobby is on.** While you are in an online lobby, a small tag at the top right names its master server, for example "Game Lobby (King)"; a server the game doesn't know is shown by its address.

## Changed

- **Balance > Units, Range.** The tooltip now says that only units with a projectile use their attack range: a melee unit always fights at arm's length, as in the original game and the FunLite ROM hack. To make a range count, give the unit a projectile in Traits.

## Files

- `LegoBattles-PC-0.3.7.zip`: the game.
- `LegoBattles-PC-0.3.7-runner-source.zip`: the corresponding source of the runner (GPL-3.0-or-later). The port's own source is this repository at this tag.
