Version 0.4.27 of the LEGO Battles PC port: no more missing-DLL errors after updating, and updates that can't break your install.

The settings menu opens with F1 or Esc. Settings > General > **Install update** updates the game in place.

## Fixes

- **"SDL2.dll (or libgcc_s_seh-1.dll, libstdc++-6.dll, libwinpthread-1.dll) was not found" after an update.**
  - The game is now a single program: everything it used to load from DLLs beside it is built in, so no DLL can go missing.
  - An update that can't finish now puts every file back as it was. Before, it could stop partway and leave the game unable to start.
  - The game also repairs an install that an earlier failed update left half-replaced.
- **The game closed at once when its folder name had accented or non-Latin letters** (for example `Jogos Ñandú` or Japanese). Such folders now work, for playing and for updates. This needs Windows 10 version 1903 or later.

## If your game shows a "…dll was not found" error

The game can't start to update itself in that state:
1. Download `LegoBattles-PC-0.4.27.zip` below.
2. Extract it over your install. Your saves, settings, mods and ROM are kept, because the zip contains none of them.

From 0.4.27 on, this can't happen again.

## Please update together

- Online, everyone in a lobby should use the same version.

## Files

- `LegoBattles-PC-0.4.27.zip`: the game.
- `LegoBattles-PC-0.4.27-runner-source.zip`: the corresponding source of the runner (GPL-3.0-or-later). The port's own source is this repository at this tag.
