## The framework: ndsrecomp

- **ndsrecomp**: the Nintendo DS static recompiler and runner framework the
  port is built on. It lifts the game's ARM9/ARM7 code to C, and supplies the
  runtime, the DS hardware model and the SDL front end that `port/runner/`
  hooks into.
- Copyright © 2026 Matthew Stanley and contributors. Upstream:
  <https://github.com/mstan/ndsrecomp>.

  - **The project as a whole:** PolyForm Noncommercial License 1.0.0
    ([text](LICENSES/ndsrecomp-PolyForm-Noncommercial-1.0.0.txt)).
  - **`runner/src/`, `recompiler/armv4t/`, `recompiler/support/`, `oracle/`:**
    MIT ([text](LICENSES/ndsrecomp-MIT.txt)). These link into the
    GPL-covered runner.
  - **`runner/vendor/melonds/`, `runner/src/melonds_compute/`,
    `runner/src/frontend.cpp`:** GPL-3.0-or-later, as derivative works of

- **The recompiler and its generated code** fall under the PolyForm

## melonDS

- **melonDS**, the Nintendo DS emulator. The runner vendors melonDS's 3D
  geometry engine and software/compute rasterisers (`GPU3D*`), its OpenGL
  support code and its Wi-Fi model (`Wifi`, `WifiAP`). These are the runner's
  3D and wireless device models; the game's own code drives them.
- The vendored files are from tag `1.0rc`. Some are modified, and the patches
  record each change (GPLv3 §5(a)).
- Copyright © melonDS team (Arisotura and contributors). Upstream:
  <https://github.com/melonDS-emu/melonDS>, <https://melonds.kuribo64.net/>.
- Licence: **GNU General Public License v3.0 or later**
  ([text](LICENSES/GPL-3.0-or-later.txt)).
- melonDS was also the reference emulator this project compared its behaviour
  against.

Because the runner links GPL-3.0-or-later code, **`LegoBattles.exe` is a
combined work distributed under GPL-3.0-or-later.** The source for the parts
that are free to share is public:

- the port's own code: this repository, at the tag of each release;
- the framework: ndsrecomp, at the revision named in
  [`port/runner/README.md`](port/runner/README.md);
- melonDS: upstream tag `1.0rc`, plus the patches in ndsrecomp.

The game's own code is lifted from your cartridge when you build. Neither this
repository nor its releases contain it, and it is not this project's to
license.

## Knowledge and data

These projects are credited for what this one learned from them. None of their
code is in the executable.

- **[LiruJ/Lego-Battles-Decomp](https://github.com/LiruJ/Lego-Battles-Decomp)**
  (CC0 1.0), itself templated from [zeldaret/ph](https://github.com/zeldaret/ph).
  It gave the ARM9 delinking configuration, the section and overlay layout,
  function extents, the first function names, the map chunk tags, and the
  overlay-to-mission mapping. See [`docs/reference/attribution.md`](docs/reference/attribution.md).
- **LegoBattlesRebalancePatch** (Ryncat, with Alpha47) and
  **opiter09's Entities Editor**: the unit table as an editable format, and
  the balance-patch data the port's Balance option reads from the player's own
  copy.
- **CUE's DS compression tools** (`blz.c`, public domain): the BLZ algorithm
  behind `tools/nds_extract.py` and the first-run USA conversion.
- Analysis tools: [Ghidra](https://ghidra-sre.org/) (Apache-2.0),
  [DeSmuME](https://desmume.org/) (GPL-2.0),
  [ds-decomp](https://github.com/AetiasHax/ds-decomp),
  [ds-rom](https://github.com/AetiasHax/ds-rom),
  [objdiff](https://github.com/encounter/objdiff),
  [NitroPaint](https://github.com/Garhoogin/NitroPaint),
  [apicula](https://github.com/scurest/apicula) (0BSD) and
  [libnds](https://github.com/blocksds/libnds).
